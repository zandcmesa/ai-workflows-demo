# ai-workflows-demo

A demo project for exploring AI-assisted workflows.

## Getting started

```bash
git clone https://github.com/zandcmesa/ai-workflows-demo.git
cd ai-workflows-demo
```

## The site

`index.html` is the **AI Workflows Field Guide**, an interactive beginner's guide to Claude and Claude Code (setup checklist, command cheat sheet, workflows, skills, token tips, videos). It's plain HTML/CSS/JS with no build step, and it's served by GitHub Pages from `main`.

Live: https://zandcmesa.github.io/ai-workflows-demo/
