# ai-workflows-demo

A demo project for exploring AI-assisted workflows.

## Getting started

```bash
git clone https://github.com/zandcmesa/ai-workflows-demo.git
cd ai-workflows-demo
```

## The site

`index.html` is the **AI Workflows Field Guide**, an interactive beginner's guide to Claude and Claude Code with two parallel paths, **Terminal** and the **Claude desktop app**, each with its own setup checklist, cheat sheet, workflows, skills notes and token tips. Link straight to a path with `?path=desktop` or `?path=terminal`. It's plain HTML/CSS/JS with no build step, and it's served by GitHub Pages from `main`.

Live: https://zandcmesa.github.io/ai-workflows-demo/
